# Abandix phase roadmap

## Phase 1 — Foundation

Project structure, design system, Next.js App Router, Supabase SSR/Auth, normalized PostgreSQL schema, RBAC, RLS, Storage, responsive navigation, admin shell, SEO foundation and safe demo seed.

## Phase 2 — Places

Published place CRUD workflow, privacy-safe coordinate display, search and filters, map/list exploration, timeline, status history, media galleries and corrections entry point.

## Phase 3 — Community

Reports, anonymous display mode, comments/replies, profiles, contributions, corrections, follows and notifications.

## Phase 4 — Archive

People, groups, sources, historical pages and Abandix Tierlist catalogue views.

## Phase 5 — Moderation

Moderation queue, user actions, bans/suspensions, audit-log tooling, retention settings and technical metadata controls.

## Phase 6 — Polish

Accessibility audit, image delivery, caching, search performance, route-level metadata, sitemap expansion, security review, rate-limit provider integration and responsive refinement.
